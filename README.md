# CivicPulse AI Hub — Tech for Humanity

An offline-first community edge AI platform providing rural health triage, adaptive STEM tutoring, and LoRaWAN crop/climate alerts without requiring constant internet connectivity.

## Key Features
- **100% Offline Edge Simulation:** Runs locally with zero cloud dependency during outages.
- **Local Dialect Voice & Text Input:** Designed for low-literacy and regional language accessibility.
- **Rural Health Triage:** Symptom assessment, red-flag detection, and first-aid guidance.
- **Adaptive STEM Tutor:** Curriculum-aligned, step-by-step explanations for students.
- **Agri & Climate Alerts:** Real-time soil moisture and weather warnings from local sensors.
- **Encrypted SQLite Mesh Sync Queue:** Stores anonymized records locally and syncs automatically when intermittent connectivity returns.

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
